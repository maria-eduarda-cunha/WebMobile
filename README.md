A aplicação consiste em uma plataforma web de ensino de libras voltada para o atendimento emergencial. Oferencendo uma experiência gamificada de aprendizado com foco em situações de urgência.

Esta página consiste em exibir os módulos de ensino de uma forma geral.

<img src="img_wireframe/1.png">

Esta página mostra as aulas e quizes referentes ao módulo selecionado anteriormente.

<img src="img_wireframe/2.png">

Ao clicar em aula na tela anterior, essa página mostrará um vídeo curto com uma professora sinalizando.

<img src="img_wireframe/3.png">

Nesta etapa do quiz, o usuário selecionará o sinal sendo apresentado no vídeo.

<img src="img_wireframe/4.png">

Nesta parte do quiz, o usuário arrastará as palavras de acordo com a ordem da frase sinalizada no vídeo.

<img src="img_wireframe/5.png">

Nesta etapa do quiz, 3 vídeos serão mostrados simultâneamentes para o usuário selecionar aquele que corresponde à frase apresentada.

<img src="img_wireframe/6.png">

Nesta etapa do quiz, o usuário arrastará o texto correspondente ao vídeo correto.
